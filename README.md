# Popcorn Stats🎬
  A CLI program with TraktAPI (made for learning Oauth2.0) 
## Description 
   Log in with your Trakt Account, discover recent popular movies and shows and search for your favorite ones.

## Getting started 
- Python 3.10+
- pip installed
- pip Flask and requests installed
- pip dotenv 
- A trakt API account with your app created (for your credentials). 
## Installation
  *1*. **Clone repository**
```bash
https://github.com/uriel-salazar/Popcorn-Stats
```
*2*. **Create .env files**
    Create a .env file with your cleint id and your client secret from your Trakt developer account.
  ```bash
     client_id="YOUR CLIENT ID "
     client_secret="YOUR CLIENT SECRET "
 ```
*3*. **Running**
  ```bash
     python main.py
 ```
